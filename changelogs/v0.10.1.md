# v0.10.1

Groundwork release. No user-facing behaviour changed; everything here is
tooling that makes the next releases verifiable.

## Testing

- **Vitest** unit suite (32 tests) covering `escapeHtml`, MIME-type gating,
  favorites/recent-tools storage, and registry invariants: unique kebab-case
  ids, valid categories, and every `select` option's default present in its own
  choice list.
- **Playwright** end-to-end suite (16 specs): home navigation, search, favorite
  persistence, and real tool runs (grayscale image, PDF merge, QR generation)
  asserting a downloadable result is produced.
- Fixtures are generated in memory - a real RGBA PNG encoder (zlib + CRC32) and
  pdf-lib built PDFs - so no binaries live in the repo.

## Tooling

- **ESLint** flat config: typescript-eslint recommended plus `no-console`,
  `no-explicit-any`, `consistent-type-imports`, `eqeqeq`, `prefer-const`.
- **Prettier** with the project's existing style (single quotes, 100 columns),
  applied across the codebase.
- `.gitattributes` normalises line endings to LF so format checks agree between
  Windows and CI.
- New scripts: `typecheck`, `lint`, `lint:fix`, `format`, `format:check`, `test`,
  `test:watch`, `test:coverage`, `e2e`, `verify`.

## CI

- GitHub Actions runs typecheck, lint, format check, unit tests with coverage, a
  production build, and the E2E suite on every push and pull request.
- `.gitignore` previously excluded all of `.github/`, which made committing a
  workflow impossible. It now excludes only AI-agent instruction files.

## Fixes

Every ESLint error found on the existing code was real dead code:

- `imageCrop`: `dragStartPx` was written on every drag start but never read.
- `qr-generator`: `bestMask` tracked the winning mask; nothing consumed it.
- `convert-tools`: `usableH` computed and unused in the text-to-PDF layout.
- `imageToBase64`, `pageNumbersPdf`: `let` + if-chain replaced with `const`.
- `pdfToImage`: `counterEl` was declared then assigned much later.
- `compressPdf`: replaced an `as any` render cast with a typed one.

## Docs

- README corrected: the site has 38 tools (13 PDF, 14 Image, 11 Convert), not
  the 30 previously listed, and the Convert category was missing entirely.
- `package.json` version aligned to the changelog (was 0.9.0).
