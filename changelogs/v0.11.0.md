# v0.11.0

Twelve tools were quietly ignoring your settings, or failing every run. This
release fixes all of them and removes the design that let it happen.

## The cause

The worker validated tool options against a Zod schema written by hand, in a
different file from the option list the UI renders. The two drifted apart. Zod
strips keys a schema does not declare and throws when a value is not in an
enum it lists, so a mismatch either discarded your choice without a word or
failed the run outright.

Validation is now derived from each tool's own option declaration, so the two
cannot disagree, and it runs on the main thread where a problem can be
reported instead of surfacing as a generic worker error.

## Fixed - settings that were being ignored

- **Extract Pages** - the page range was discarded; every run extracted pages
  1-3 regardless of what you typed.
- **Resize PDF Pages** - size and orientation were discarded; every run
  produced A4 portrait.
- **Crop Image** - the crop box was discarded; every run used the default
  selection.
- **Color Palette** - the colour count was discarded; every run returned 8.
- **PDF Metadata** - Keywords and Producer were discarded and could not be
  edited.
- **Resize Image** - "keep aspect ratio" was discarded.
- **Merge / Stack Images** - alignment and background colour were discarded.
- **Add Page Numbers** - the number format (1, 1 of N, - 1 -) was discarded.
- **Add Blank Page** - the page position and size were discarded.

## Fixed - tools that failed on every run

- **Compress PDF** - the quality selector offered values the validator
  rejected, so every run ended in an error.
- **Add Page Numbers** - same, for position.
- **Flip Image** - "Both" was rejected.
- **Add Blank Page** - "Beginning of document" and "After page number" were
  rejected.

## Removed

- **Lock PDF** was never registered, had no worker route and no implementation.
  It could only ever have thrown. pdf-lib cannot encrypt, so a real version
  needs its own work; the stub is gone.
- Nine tools carried an unused `process()` fallback from before processing
  moved into the worker. 451 lines of unreachable code removed, along with
  `Tool.process` and `ToolResult`.

## Tests

- `tests/tools/optionsContract.test.ts` re-derives from source what each worker
  handler reads and compares it against what the UI supplies, and checks every
  declared default and every select value survives validation.
- `e2e/repaired-tools.spec.ts` proves the fixes behaviourally: extracting pages
  4-6 yields 3 pages, A3 landscape comes out wider than tall, keep-ratio maps a
  16x4 image to 64x16, a 5-colour palette returns 5 swatches. Eight of the ten
  fail against the previous release.
